Connection

MetaTrader 5 connects via the TradingBotZmqEA.mq5 Expert Advisor. Attach the EA to a chart and it will auto-connect using the ZMQ ports configured for this instance.

Default MetaTrader ports: 5565 (market), 5566 (commands), 5567 (queries), 5568 (heartbeat).

Make sure the EA inputs match the ports this Python instance is bound to.
